## Steps to Run the API

1. **Prerequisites:** Ensure you have Java 21, Maven, and PostgreSQL installed on your machine.
2. **Database Setup:** Create a PostgreSQL database named: **attendance_db**.
3. **Configuration:** Open the **src/main/resources/application.properties** file and update the **spring.datasource.username** and **spring.datasource.password** to match your local PostgreSQL credentials.
4. **Run the Application:** Open your terminal in the root directory of the project and run the following command:
   ```bash
  ** ./mvnw spring-boot:run**
